# Digit Seatbelt

Digit Seatbelt is an open-source project exploring a transparent safety layer between users, applications, and AI systems.

## Mission

Build a model-agnostic safety middleware that provides:

- Risk detection
- Transparent triggers
- Explainable interventions
- Open governance

## Status

Early prototype and research phase.

## Goals

- Publish architecture
- Build proof-of-concept middleware
- Create trigger engine
- Gather community feedback
