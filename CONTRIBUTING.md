# Contributing to Digit Seatbelt

Thanks for your interest in contributing to Digit Seatbelt.

Digit Seatbelt is an open safety infrastructure project focused on transparent, model-agnostic safeguards for human-AI interaction. We welcome contributions from researchers, engineers, designers, and community members.

## Ways to contribute

- Report bugs or edge cases in safety triggers and interventions
- Propose design improvements for the trigger engine and middleware
- Share examples of real-world AI risk scenarios
- Improve documentation, architecture notes, and examples
- Help prototype new governance and evaluation workflows

## Principles

We aim to keep contributions aligned with the project mission:

- Transparent safety decisions
- Explainable interventions
- Model-agnostic design
- Open governance and review
- Human-centered risk mitigation

## Before you contribute

Please keep the following in mind:

- Be respectful and constructive in discussions
- Focus on measurable safety and usability improvements
- Document assumptions, trade-offs, and limitations clearly
- Prefer small, reviewable changes when possible

## Suggested contribution flow

1. Open or review an issue to discuss the proposed change.
2. Share your design or implementation approach in the issue or discussion.
3. Submit a focused pull request with clear motivation and validation.
4. Include documentation or examples when behavior changes.

## Pull request expectations

A good pull request should:

- Explain the problem being solved
- Describe the proposed approach
- Note any trade-offs or limitations
- Include tests or validation steps where applicable
- Keep scope narrow and understandable

## Community guidelines

We value collaboration, clarity, and thoughtful feedback. Contributions should help move the project toward safer and more transparent human-AI systems.

If you are unsure where to start, begin by opening an issue to discuss an idea or a pain point. We are happy to help shape a first contribution.
